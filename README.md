# Срез — локальная проверка контрагента без сервера

Клиент в браузере. Бэкенда нет. Источники — **официальные машиночитаемые каналы**, не HTML-сайты с формами.

## Какие API, без капчи

Капча сидит на **сайтах** (`egrul.nalog.ru`, `kad.arbitr.ru`). К обсуждаемым официальным интерфейсам она не относится.

| Задача | Официальный канал | Как в этом приложении |
|---|---|---|
| Статус ЮЛ | Интеграция ЕГРЮЛ/ЕГРИП ФНС, XML 4.07/4.08 | Файл выгрузки в форму |
| Налоги | Open Data ФНС (ст. 102 НК): `debtam`, `paytax`, `taxoffence`, `sshr`, `snr` | XML-набор в форму, разбор по ИНН |
| Банкротство | REST ЕФРСБ `bank-publications-*.fedresurs.ru` | Логин/пароль только в `localStorage`, запрос с этой машины |
| Суды | Публичного официального API КАД нет | Канал не подключается |

«Прозрачный бизнес» и картотека арбитража — веб-витрины, не API.

Ограничение браузера здесь одно: **CORS**. Официальный REST ФНС/Федресурса почти никогда не отдаёт `Access-Control-Allow-Origin`. Со статической страницы `fetch` падает; расширение Chrome ходит на те же API с компьютера пользователя и CORS не мешает. Это всё ещё не ваш сервер.

Публичный API ФССП (`api-ip.fssp.gov.ru`) с 2022 года выключен. В контур «статус / налоги / банкротство / суды» он и не входил.

## Запуск

```bash
npm install
npm test
npm run dev
```

Расширение для живого REST ЕФРСБ:

```bash
npm run build
```

Папка `dist-extension/` → Chrome → режим разработчика → загрузить распакованное.

Ключи Федресурса в демо-контуре выдаёт оператор (спецификация на fedresurs.ru). Прод — по договору.
