# Срез — локальная проверка контрагента без сервера

Веб-приложение для экспресс-проверки ЮЛ/ИП: **статус ЕГРЮЛ, налоги, банкротство, суды и признаки технической организации**.  
Данные собираются **на странице в браузере**. Классического бэкенда нет: HTTP уходит с компьютера пользователя.

## Почему обычный сайт сам не вытянет ФНС и КАД

Браузер режет чужой домен политикой **CORS**. У `egrul.nalog.ru`, `pb.nalog.ru`, `kad.arbitr.ru`, `bankrot.fedresurs.ru` заголовка `Access-Control-Allow-Origin` нет.  
`fetch()` со статической страницы падает, даже если вы открыли её с GitHub Pages или `file://`.

Капча ЕГРЮЛ/КАД тоже не обходится: это не «ещё один API».

Поэтому без вашего сервера остаются только честные каналы:

| Канал | Что умеет | Ограничение |
|---|---|---|
| XML-выписка ФНС, файл в форму | Полный статус, директор, адрес, недостоверность, УК | Нужно скачать выписку с egrul.nalog.ru |
| Open data ФНС (ZIP/XML на диск, потом в приложение) | Недоимка, уплаченные налоги, численность | Объёмные дампы, не realtime |
| Расширение Chrome | Запрос с вашего IP, без CORS | Капчу всё равно проходит человек |
| Кнопки «открыть реестр» | ЕГРЮЛ, Прозрачный бизнес, ЕФРСБ, КАД, Вестник | Данные смотрите на чужой странице, мы её не читаем |

Публичный CORS-прокси — это уже чужой сервер. В архитектуру его нет.

## Что проверяется

- Контрольная сумма ИНН (10 / 12).
- Карточка из выписки: статус, руководитель, учредители, адрес, ОКВЭД, УК.
- Признак технической организации — не реестр ФНС, а **совокупность маркеров** (численность 0–1, недостоверность ЕГРЮЛ, дисквалификация, нулевые налоги, массовый директор/адрес, нулевые ОС). Один флаг не делает компанию «однодневкой».
- Ссылки на банкротство (ЕФРСБ), арбитраж (КАД), Вестник, open data ФНС.

## Запуск

```bash
npm install
npm run dev
```

Сборка статики и папки расширения:

```bash
npm run build
```

- сайт: `dist/`
- расширение: `dist-extension/` → Chrome → `chrome://extensions` → режим разработчика → «Загрузить распакованное»

Демо-отчёт: кнопка «Показать демо-выписку».

## Юридическая рамка

Сведения ЕГРЮЛ и open data ФНС общедоступны. Приложение не выдаёт заключение «это техническая компания» — только список сработавших открытых признаков и дату среза. Капчу и закрытые API обходить нельзя.
